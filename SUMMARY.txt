ALGORITHM STEPS
---------------
1. Compute quadric error matrix for each vertex
2. Build priority queue of edge collapses
3. Validate topology (manifold, no degeneracies)
4. Iteratively collapse lowest-cost edges
5. Rebuild clean output mesh
